are preserved evidence from Factory's retired self-hosting workflow. Their
stage labels, review stops, absolute paths and commands are historical, not
instructions for developing this repository. Some links refer to the retired
local runtime and will not resolve in a clone.

The [current roadmap](../../roadmap.md) is authoritative for delivery status.
Draft plans for 0032 and FH-04 are deferred proposals, not completed code.
The Sortly [source retrospective](2026-09-04-harness-improvement-retrospective.md)
is preserved with its original project-specific evidence boundaries.
The old 0026 depth-recorder branch is preserved in Git archive tags; its
routing improvements were ported without restoring its obsolete depth model.

Before consolidation, all branch history and uncommitted worktree files were
also backed up outside the repository. See the consolidation report for the
local recovery location and verification results.
